# Code Black WX — Brand Reference v1

## Brand essence
**Field command. Storm intelligence. Livestream broadcast.**

Code Black WX should feel **black-first, high-contrast, tactical, credible, urgent, and disciplined**. It should not feel like a generic SaaS dashboard, gaming UI, cyberpunk HUD, or neon/RGB package.

## Primary mark
Use the supplied Code Black WX logo **as provided**. Do not redraw, reinterpret, regenerate, trace, or replace the mark. The logo is a reference for the broader visual language: shield structure, condensed white typography, tornado/lightning motifs, black field, and vivid red-orange accent.

## Core palette
- Code Black: `#000000`
- Signal Red (logo/brand accent): `#FF2A0C`
- White: `#FFFFFF`
- Gunmetal: `#171A1D`
- Utility Gray: `#8D949B`

### Operational warning colors
These are **semantic**, not decorative brand colors.
- Tornado Warning: red
- Severe Thunderstorm Warning: yellow
- Warning semantics override decorative brand styling.

## Typography direction
- Headlines: tall, condensed, bold, mostly uppercase.
- Data: neutral highly legible sans serif.
- Prefer tabular numerals for telemetry when available.
- Strong hierarchy; avoid excessive type sizes competing at once.
- Do not mimic the logo lettering unless the actual licensed/available typeface is known.

## Shape language
- Sharp / clipped corners.
- Diagonal cuts and purposeful angles.
- Shield-like structural cues may appear subtly.
- Thin tactical rules and separators.
- Prefer strips, rails, and layered broadcast framing over equal-weight rounded cards.
- Avoid soft “app card” grids and glassmorphism as the dominant visual language.

## Motion language
- Quick, deliberate wipes, reveals, and directional transitions.
- Motion should feel broadcast/operational, not game-like.
- No constant pulsing, RGB cycling, gratuitous glow, or nonstop flashing.
- Alerts may temporarily become more visually dominant.
- Respect reduced-motion behavior where applicable.

## Stream overlay rules
- Broadcast overlay first; application dashboard second.
- Preserve a large clear storm-video safe area.
- Normal-state graphics should be restrained and edge-anchored.
- Storm Intel should read as one integrated environmental rail/reveal, not a wall of unrelated cards.
- Hodographs must remain scientifically useful while visually belonging to the package.
- Tornado/Severe alert states may temporarily dominate the frame.
- Public overlay hides internal vehicle names by default.
- Public identity uses configured first + last name unless explicitly changed.
- Use the motto **“From Watching to Warning.”** sparingly.

## Do
- Use true black/charcoal as the primary field.
- Use white for primary information.
- Use Signal Red sparingly for identity and emphasis.
- Use genuine supplied logo assets.
- Use strong condensed hierarchy.
- Use angular broadcast framing.
- Keep operational state colors semantically correct.
- Design for real OBS stream resolution and video visibility.

## Don't
- Do not recreate or AI-regenerate the logo.
- Do not turn every data point into a floating card.
- Do not overuse brand red.
- Do not use gaming RGB, cyberpunk neon, or excessive glow.
- Do not rely on rounded SaaS cards.
- Do not make every metric visually equal.
- Do not confuse modeled data with observations.
- Do not expose internal fleet/vehicle names on the public overlay by default.

## Visual test
A Code Black WX graphic should still feel recognizably **Code Black** even if the main logo is temporarily hidden.
