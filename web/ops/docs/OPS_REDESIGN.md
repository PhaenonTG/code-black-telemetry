## Aegis integration pass (2026-10-12)

Analysis Setup, Surveillance, Chase, Radar Lab, Map, Weather Analysis and the retained Chase Targets page now share one selected-point review controller. Producer retains a separate, explicitly identified Core-unit briefing. Selecting a setup or echo does not arm a target, route a vehicle, issue an alert, or run a model. An operator can request a local review; only exact latitude/longitude are sent to Core's existing `POST /api/ai/v1/target-analysis`. The configured-unit refresh uses `POST /api/ai/v1/assessment/refresh`. Neither accepts a paid provider/model override. Minute GET polling reads published state only.

The actual model schema's `environment_summary` and supporting findings now render, rather than falling back to generic success text. Reviews show their point/unit context, model, source time, snapshot and evidence limits. Setup forecast-hour metadata is retained, but the UI explicitly warns that this endpoint reviews current conditions, not the setup's future valid hour. A fleet briefing is never represented as a selected-point or different-unit briefing. Expired/unknown timestamps, guard rejection, source failure and newer radar evidence remain visible.

Requests are single-flight, have a per-point/unit thirty-second browser cooldown and no automatic retry, and retain the last confirmed result on network failure. Responses arriving after a point switch are attached only to their original coordinates. Up to twelve exact-point results are retained for the session, not persisted as training data. Server-side rate limiting remains a separate backend concern; a browser cooldown is not a security control.

Cell Watch and map overlays use only published dominant-echo evidence. The site, location and observation clocks must be present. The envelope and cell must both be fresh; a usable estimate also requires trusted reflectivity at the same site and a positive scan-pair interval. The UI flags a mismatch with the displayed radar site. Stale/failed evidence removes the current map marker and disables selection. Bounded session observations are not connected into an invented storm trail: `KSRX-primary` is an aggregate dominant centroid, not a persistent multi-cell tracking identity. No tornado, rotation or pixel-level visual interpretation is inferred from these fields.

The deployment's Advanced Mode gateway was dropping POST bodies (only PUT bodies were forwarded). That path now carries POST JSON and normalizes the two local-review contracts through the same small validation helper used by the private VPC transport and folder-based Function. Exact methods, finite coordinate ranges, body size, active-profile authentication, fixed Core paths, and provider/command rejection are covered by tests. Local review calls have a bounded ninety-second transport deadline instead of the ordinary eight-second read deadline. The private transport's timer and caller cancellation are tested too. Existing diagnostics and other explicitly allowed operations are not removed. Retired map-canvas events are ignored so an unmounted canvas cannot cover its replacement with a false fatal map error.
